# Sachit — Developer Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and interactive motion/3D elements.

**Live site:** https://sachin-portfoli.vercel.app  
**GitHub:** https://github.com/sachit1751-art  
**Contact:** sachit1751@gmail.com

## Overview

The site presents selected web, Android, and AI-integration projects, plus technical focus and contact links. Its visual direction uses a paper-inspired interface with motion and Three.js/WebGL effects.

## Currently building

**OutreachOS** — a personal CRM for startup research, contacts, outreach history, and follow-ups. It is still in development; the generated code needs local setup and runtime/workflow validation before it should be treated as ready to use.

## Selected projects

- **Community Management Platform** — a full-stack project focused on resident communication, announcements, chat, and role-aware access. Source code is private.
- **[SKY ROMs](https://github.com/sachit1751-art/SKY-website-v2)** — web platform for discovering Android custom ROMs. [Live demo](https://sky-roms.vercel.app/).
- **[MoneyPal](https://github.com/sachit1751-art/MoneyPal)** — native Android budgeting app with recurring expenses and a Wear OS companion.
- **[Audify](https://github.com/sachit1751-art/Audify)** — native Android music player with playback, queue, lyrics, and library features.
- **[ZNS Nexus](https://github.com/sachit1751-art/zns-nexuso)** — motion-focused web experience.

See each public repository for its implementation details, setup instructions, and current limitations.

## Tech stack

- React, TypeScript, Vite, Tailwind CSS
- Three.js, GSAP, Motion for React
- Node.js and Express
- Kotlin, Jetpack Compose, Android SDK
- PostgreSQL, Supabase, REST APIs

## Run locally

Requirements: a compatible Node.js version and npm.

```bash
npm install
npm run dev
```

Available checks:

```bash
npm run lint
npm run build
```

Review `package.json` for the exact scripts and dependencies in this repository.

## Notes

- Keep secrets in environment variables; do not commit local environment files.
- Verify project demos and repository links before relying on them.
- The portfolio is a presentation site, not a substitute for reviewing each project's source code.
